HR Analytics Dashboard:
This project presents a "comprehensive Human Resources Data Analysis Dashboard" that helps visualize and analyze employee data, providing actionable insights for HR decision-making.

🛠️ Tools & Techniques
Pivot Tables for data grouping and analysis  
Pivot Charts for interactive visualizations  
Slicers for dynamic filtering  
Data analysis on employee satisfaction, salaries, projects, and sick leave patterns  

Key Performance Indicators:
Total Employees: 11,991  
Employee Satisfaction: 63%  
Total Projects: 45,600  
Average Monthly Hours/Week: 200 hours  

 Chart Explanations
Employee Satisfaction: Column chart showing satisfaction per department (54%-72%)  
  - Highest: Accounting | Lowest: Technical Support  
Project Distribution: Area chart displaying project count by department  
  - Sales leads with the highest number of projects  
Salary Analysis: Comparison of average salaries across departments  
  - Highest: Sales & Technical Support | Lowest: Management & Accounting  
Sick Leave: Absence rates by department (0%-30%)  
  - Highest: Sales (25%) | Lowest: Accounting & Management  
Interactive Filters: Department and salary filters with automatic chart updates  

🚀 Skills & Challenges
- Analyzed large datasets of over 11,000 employees  
- Created clear and measurable KPIs  
- Connected and organized data from multiple sources  
- Designed user-friendly visual interfaces  
- Extracted actionable insights to support decision-making  

  Key Insights
- Variation in satisfaction levels between departments needs attention  
- Higher-paid departments show more sick leave – correlation to investigate  
- Uneven project distribution – opportunity for rebalancing  
- Need for a comprehensive plan to improve employee satisfaction and productivity
